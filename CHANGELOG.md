# Changelog

All notable changes to Sinew for Kotlin are documented here. Every module shares one version (lockstep).

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [Unreleased]
- S3 `sinew-network` (#20): `processApiCall` and `processOptionalApiCall` (a 404 is `null`): envelope `failure()` → `ValidationException` or `ApiErrorException` before `toDomain()`, `message()` → `Success.message`. The public `apiHandlers` table (timeouts and lost connections anywhere in a failure's cause chain, never when a TLS or certificate failure is in it; every 5xx but 503 and 504 → `ServerException`; 408 to the catch-all; unreadable JSON and a missing payload → reported `ParseException`), with per-platform predicates for OkHttp, Darwin and the browser, and Ktor's own `ResponseException` classified by status. `RefreshResult.from(result)` for a guarded refresh call.
- S3 `sinew-network` (#19): `SinewAuth` (the token only for `baseUrl`'s host and port outside the exact anonymous paths; one refresh for any number of 401s through `SingleFlightRefresher` in the client's scope; a 401 for an older token replays at once; one replay per request; `Rejected` and a replayed 401 return the 401; `Unavailable` throws its cause and keeps the session; a request's own `Authorization` and a 401 after sign-out are left alone; a one-shot body refreshes but isn't replayed), `SinewHttp.resetAuth`, and `SessionTokenSource` with `RefreshTokenStore`, `RefreshCall` and `RefreshResult` (session epoch, `start`, `onSessionEnded`, a rejection ending only the session it started in). Every layer is now a public plugin installable alone (`sinewBackend(url)`, which sets `defaultRequest` and gives the plugins the base URL once, `SinewAuth`, `SinewHeaders`, `SinewTimeouts`, `SinewRedirect` with `maxHops`, `SinewLog`, and `HttpResponseValidator { sinewErrorBody() }`), each failing fast on a missing setting; `SinewHttp.client` is the optional preset built from them and now takes the `TokenSource`. `sinew-testing`: `FakeTokenSource`.
- S3 `sinew-network` (#18): `SinewHttp.client` on the platform engine or an explicit one (OkHttp, Darwin, Js), with `SinewJson`, per-method deadlines that a request's own `timeout { }` overrides, the JSON, language and default headers read per request, a validator that reads failed bodies with the config's `ErrorBodyReader` and throws after redirects, `SinewRedirect` (GET/HEAD, five hops, no HTTPS downgrade, `Authorization` and `Cookie` dropped across hosts) and `SinewLog` with `HttpLogger` (one line per exchange, never a header, body or query).
- S3 `sinew-network` (#17): `SinewConfig` (validated on construction; `locale` and `defaultHeaders` read per request), `TokenSource` with `RefreshOutcome` (`Refreshed`, `Rejected`, `Unavailable(cause)`) and the `clear()` epoch contract, `ErrorBodyReader` with a `Default` that reads JSON `message` and `errors`, and the internal `HttpStatusError(status, errorBody, retryAfter)` with `Retry-After` in seconds or an HTTP date; replaces the S0 placeholder.
- S2 `sinew-viewmodel`: `StateEffectViewModel` and `EventActionViewModel` on the multiplatform AndroidX `ViewModel` (actions in `viewModelScope`, clean-up through `addCloseable`, events after clearing ignored) and `ObserveEffects` (`repeatOnLifecycle(STARTED)` on `Dispatchers.Main.immediate`); replaces the S0 placeholder.
- S2 `sinew-presentation`: `EffectEmitter` (buffered, delivered once, dropped beyond 64), `StateEffectHandler` (`StateFlow` state, `setState`, `emitEffect`, `dispose` closing effects and cancelling the scope) and `EventActionHandler` (`onEvent` → pure `mapEventToAction` → `onAction` launched in the scope; events after `dispose` ignored); replaces the S0 placeholder.
- S2 `sinew-paging`: `LoadType`, `PagingState` (`canLoadMore`, `retryType`), the four strategies behind `Pager.offset`, `offsetByTotal`, `cursor` and `lastItem` (the requested page wins; cursor and last-item have-next rules), and `Pager.load` (`Mutex`, child-job fetches cancelled when superseded, stale responses dropped by request id, `Initial` once per query, `itemKey` de-duplication) and `cancel()`. `sinew-testing`: `ControlledFetch`. `checkSinewGraph` allows `sinew-testing` from test source sets only.
- S1 `sinew-l10n`: `SinewStrings` (keys, suspending `resolve` for a key, arguments and resource environment) and `rememberSinewLocalizer` (the app's strings first, then Sinew's from a per-language preloaded cache); fixes the English apostrophes, which Compose resources don't unescape; replaces the S0 placeholder. `rateLimitedNoTime`'s English fallback now matches its resource.
- S1 `sinew-exception`: the 19 built-in types (no `CancelException` on Kotlin), `ExceptionHandler`, `envelopeDataMissing`, `processCall` (cancellation first, pass-through, first-match handlers, reporting of unexpected and parse failures), `processResult`, `CrashReporter` (`None`, `install`, `current`), `Localizer` and `displayMessage`; replaces the S0 placeholder.
- S1 `sinew-models`: `Domain`, `Remote`, `Entity`, `PlatformContext`; the error base contract (`SinewException` with `errorMessage`, `ExceptionLayer`, `ErrorMessage`, `EnvelopeDataMissing`); `Envelope` with the optional `failure()` and `message()` hooks, `EnvelopeFailure`, the four envelope bases, `PagingMetaEnvelope` and the `DomainNotParsed` stub serializer; `PagingDomain`, `PagingMetaDomain`, `PagingEntity`, `ViewState`, and Sinew's own `Result` (`Success(data, message)` / `Failure(error)`) in place of `kotlin.Result`.
- S0: project skeleton. One Kotlin Multiplatform module per Sinew package (Android, iOS, JVM, wasmJs), the `com.srctool.*` convention plugins, split version catalogs, the dependency-graph check, the BOM and the sample app.
